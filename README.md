# VikingWarrior

VikingWarrior is a standard Minecraft 64x64 pixel skin of a rugged Scandinavian Viking warrior. This skin features blond braided hair, blue eyes, a short brown beard, a dark brown leather tunic, beige fur shoulders, a metal belt buckle, leather bracers, dark trousers, and fur-trimmed brown boots. The design includes subtle Nordic rune patterns, adhering to classic Minecraft pixel art style with crisp square pixels. The skin is compatible with Java Edition and follows the correct Minecraft UV layout.

## Install

1. Download the `viking_warrior.svg` file from the project repository.
2. Convert the SVG file to a PNG format using a tool like Inkscape or any online SVG to PNG converter.
3. Ensure the PNG is 64x64 pixels and transparent.
4. Use a Minecraft skin changer mod or website to apply the PNG file to your Minecraft character.

## Use

1. Launch Minecraft.
2. Apply the VikingWarrior skin using your preferred skin changer mod or website.
3. Enjoy playing as a Viking warrior with the unique Nordic-inspired design.
